This branch was created from the previous "tutorials" so many additions are shown from that pull request, but the only modification is the addition of "convert" as task for converting from a specific saved format to another intended for publish the model. 

With this new addition we can convert several checkpoints in a row to the desired format, now is intended to convert from fsdp checkpoints to huggingface. This will let us test those checkpoints without publishing to huggingface directly.
